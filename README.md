# Rooz 1.1.1 — برنامه‌ریز فارسی

نسخهٔ بازطراحی‌شدهٔ Rooz با Flutter؛ شامل داشبورد روزانه، تقویم جلالی، گزارش ماهانه و تنظیمات ظاهر و اعلان.

## ویژگی‌ها

- رابط کاملاً فارسی و راست‌چین با طراحی مینیمال با پالت سرمه‌ای/آبی و خاکستری، سازگار با حالت روشن و تیره
- چهار بخش: امروز، تقویم، گزارش و تنظیمات
- تقویم جلالی برای انتخاب تاریخ و مرور کارهای هر روز
- افزودن، ویرایش، حذف و تکمیل تسک‌ها
- دسته‌بندی کارها: شخصی، مطالعه، کار و سلامت
- یادآوری محلی روی iOS و Android؛ در وب زمان‌بندی اعلان آینده پشتیبانی نمی‌شود
- گزارش ماهانه با نمودار ستونی انباشتهٔ انجام‌شده/باقی‌مانده و درصد تکمیل
- ذخیرهٔ محلی داده‌ها
- حفظ کلید ذخیره‌سازی `rooz_tasks_v1` برای مهاجرت خودکار تسک‌های نسخهٔ قبلی

## اجرای وب در ویندوز

در PowerShell:

```powershell
cd "$HOME\Desktop\rooz_app"
$env:PUB_HOSTED_URL="https://pub.flutter-io.cn"
$env:FLUTTER_STORAGE_BASE_URL="https://storage.flutter-io.cn"
flutter pub get
flutter run -d edge
```

## آماده‌سازی iOS از ویندوز برای Build ابری

1. اگر پوشهٔ `ios` در پروژه وجود ندارد، یک‌بار اجرا کن:

```powershell
flutter create --platforms=ios --org com.kiarash .
```

2. فایل `codemagic.yaml` در ریشهٔ پروژه قرار دارد.
3. کل پروژه را به یک مخزن خصوصی GitHub بفرست؛ پوشهٔ `ios` و فایل‌های `lib`، `pubspec.yaml` و `codemagic.yaml` باید commit شوند. پوشه‌های `build` و `.dart_tool` را نفرست.
4. مخزن را در Codemagic متصل و workflow با نام `Rooz iOS unsigned IPA` را اجرا کن.
5. فایل `Rooz-unsigned.ipa` را از بخش Artifacts دریافت کن.
6. IPA بدون امضا را با Sideloadly در ویندوز و Apple ID خودت امضا و از طریق USB روی iPhone X نصب کن.

Workflow از Xcode 26.4 و حداقل iOS 15 استفاده می‌کند. Xcode و macOS را Codemagic فراهم می‌کند؛ برای این Build نیازی به خرید Mac نیست.

## نکات اعلان iOS

- اولین بار که یادآوری زمان‌بندی می‌کنی، مجوز اعلان از iOS درخواست می‌شود.
- اگر مجوز رد شود، تسک همچنان ذخیره می‌شود اما اعلان زمان‌بندی نمی‌شود. مجوز را از Settings > Notifications > Rooz فعال کن.
- برای تست، تاریخ و ساعت یادآوری باید در آینده باشد.
- در iOS، اعلان‌های زمان‌بندی‌شده محلی توسط سیستم‌عامل مدیریت می‌شوند و لازم نیست برنامه در زمان اعلان باز باشد.

## وابستگی‌ها

این نسخه با Flutter 3.47.9 / Dart 3.13 و `flutter_local_notifications` 22.3.3 تنظیم شده است.
