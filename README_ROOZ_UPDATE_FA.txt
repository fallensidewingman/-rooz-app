Rooz 1.2.0 - Weekly recurrence + ChatGPT plan import
====================================================

محتویات بسته
-------------
- install_rooz_features.py : نصب تغییرات روی کد فعلی پروژه
- sample_plan.rooz         : فایل نمونه قابل واردکردن
- CHATGPT_PROMPT_FA.txt    : متن آماده برای درخواست ساخت فایل از ChatGPT

نصب
---
1) از پروژه Rooz یک کپی پشتیبان بگیر.
2) این سه فایل را در پوشه اصلی پروژه قرار بده؛ همان پوشه‌ای که pubspec.yaml در آن است.
3) در PowerShell از همان پوشه اجرا کن:

   python install_rooz_features.py
   flutter pub get
   flutter analyze
   flutter test

4) اگر analyze و test بدون خطا تمام شدند، برنامه را اجرا یا از Codemagic بیلد بگیر.

اسکریپت قبل از تغییر، از lib/main.dart و pubspec.yaml پشتیبان کنار همان فایل‌ها می‌سازد.
اگر الگوی مورد انتظار را در کد پیدا نکند، متوقف می‌شود و فایل‌های اصلی را نمی‌نویسد.

قابلیت‌ها
---------
- فعال‌کردن تکرار هفتگی و انتخاب چند روز با هم
- میان‌بر روزهای کاری، پنجشنبه/جمعه و هر روز
- وضعیت انجام مستقل برای هر نوبت؛ تیک شنبه وضعیت دوشنبه را عوض نمی‌کند
- نشان تکرار هفتگی در کارت تسک
- نمایش نوبت‌ها در صفحه امروز، تقویم و گزارش ماهانه
- یادآوری هفتگی در روزها و ساعت انتخابی
- واردکردن فایل .rooz از صفحه تنظیمات > داده‌ها
- پیش‌نمایش تعداد و چند مورد از تسک‌ها پیش از ورود
- ردکردن موارد تکراری و افزودن موارد جدید بدون حذف تسک‌های فعلی
- پشتیبانی از تاریخ میلادی و شمسی در فایل
- حفظ سازگاری با تسک‌های قدیمی ذخیره‌شده

ساختار فایل .rooz
-----------------
فایل .rooz در واقع JSON با یک قالب مشخص است؛ هیچ کدی داخل آن اجرا نمی‌شود.

ریشه فایل:
{
  "format": "rooz",
  "version": 1,
  "title": "عنوان برنامه",
  "calendar": "jalali",
  "tasks": []
}

فیلد calendar می‌تواند jalali یا gregorian باشد و پیش‌فرض gregorian است.
تاریخ هر کار در date یا startDate و به‌شکل YYYY-MM-DD ثبت می‌شود.
reminderTime اختیاری است و قالب HH:mm دارد.
repeatWeekdays اختیاری است و اعداد آن بر اساس Dart DateTime هستند:
دوشنبه=1، سه‌شنبه=2، چهارشنبه=3، پنجشنبه=4، جمعه=5، شنبه=6، یکشنبه=7.
برای یک کار هفتگی، تاریخ آن تاریخ شروع سری است و تکرار تا زمان ویرایش یا حذف تسک ادامه دارد.
برای برنامه محدود مثلاً ۹۰ روزه، هر نوبت را به‌صورت کار تاریخ‌دار جدا وارد کن و از repeatWeekdays استفاده نکن.

نکات
----
- حداکثر حجم فایل: ۲ مگابایت.
- حداکثر تعداد آیتم‌ها: ۱۰۰۰.
- واردکردن فقط به فهرست فعلی اضافه می‌کند؛ تسک‌های موجود پاک نمی‌شوند.
- اعلان‌ها به مجوز سیستم‌عامل وابسته‌اند.
- محدودیت تعداد اعلان‌های معلق iOS/Android ممکن است برای تعداد بسیار زیاد یادآوری‌ها اثر بگذارد.
- نسخه فعلی تکرار هفتگی را بدون تاریخ پایان نگه می‌دارد؛ برای برنامه زمان‌دار از تاریخ‌های جداگانه استفاده کن.
